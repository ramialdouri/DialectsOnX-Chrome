# DialectsOnX — Cursor notes

Chrome MV3 client for Dialex. Product source of truth is Dialex-Android (`PROMPT_VERSION`, 293 dialects, 58 System Language packs). Do not reintroduce a DialectsOnX Render/Grok translator.

## Stack

- `extension/` Manifest V3, no bundler
- Dialex `POST /translate`, `POST /faw`, `GET /faw/fingerprint`, `POST /stt`
- Catalog generated by `scripts/gen_dialects.py` from a sibling Dialex-Android checkout

## Behavior that must hold

- Always overlay tweet text. Never `innerHTML = translation` on `[data-testid="tweetText"]`.
- Auto-translate **off** when the pref is unset; stored `true` is kept. Original tap translates that post.
- Gray/official verified badge → MSA when News → MSA is on. Gold/business badges are not official.
- Dialect Selector opens the Dialex sheet (not 16 radios). Sheet pick sets default dialect and retranslates **that** post. IME sheet pick is IME-only.
- System Language is independent of destination dialect. No English fallback for `dox_*` keys when the pack is not English.
- FAW is the Pad system: `client_source=dialectsonx` is identity only. IME cannot POST `/faw`. Pad and DialectsOnX share promoted overlays automatically on the Dialex backend. Chatterbox FAW is a different admin page and does not auto-copy.
- Fonts: system UI stack only. No `@font-face` Dialex Latin.

## Local Dialex

Point Settings → Backend URL at `http://127.0.0.1:8000` while uvicorn runs from Dialex-Android `backend/`.
